Admit Card Builder

Load the exam schedule from a CSV or Excel file and print a seating card for every student.

Find your admit card

1 Exam data file

One row per student per paper. Columns: Registration No, Name, Father Name, Program, Course Code, Course Title, Date, Time, Room, Seat No, optional Photo.

2 Exam details

Logo, photos and card wording

Name each photo after the registration number, e.g. FA23-BCS-014.jpg.

3 Students

    The student copy is a single HTML file with this data built in. Students open it, enter their registration number and print their own card.

    This preview cannot print or download files. Open admit-card-app/index.html in a browser to print cards or build the student copy.
